# Contributing to BoardLite

Issues and pull requests are welcome.

BoardLite is licensed under the MIT License. By submitting a contribution, you agree that it may be included under that license.

Do not commit secrets, `.env` files, or reload URLs that contain access keys. A report export and a copied link store any URL you paste on a table.

Run `npm test` before opening a pull request. `npm run build` must pass as well.
